# Плавучесть судна — iOS Quiz

Интерактивный SwiftUI-тест по 9 контрольным вопросам лабораторной работы.

## Получение unsigned IPA через GitHub Actions
1. Создайте пустой GitHub-репозиторий.
2. Загрузите всё содержимое этого архива в корень репозитория.
3. Откройте вкладку Actions → Build unsigned IPA.
4. Нажмите Run workflow (или просто сделайте push в main).
5. После сборки скачайте artifact `PlavuchestQuiz-unsigned`.
6. Внутри будет `PlavuchestQuiz-unsigned.ipa`.

IPA намеренно собирается без code signing.
